# Click.n.likes storytelling framework selection

Six storytelling frameworks are mapped to Click.n.likes' content verticals in
`docs/content-frameworks.md` at the root of this repo. Read that file in
full before writing anything — it explains not just which framework fits
each vertical, but *why*, and which frameworks are deliberately rejected for
that use. That reasoning matters more than the framework names themselves;
don't apply a framework just because it's on the list if the doc argues
against it for this content type.

## How to use this skill

1. **Identify the vertical** the current request matches (cold email, case
   study, website copy, personal LinkedIn, company social, reel/video
   script, ad copy, blog post, or sales-call framing).
2. **Read the matching section of `docs/content-frameworks.md`** and note
   which framework(s) it names as primary/secondary for that vertical, and
   why.
3. **State the framework choice briefly** before writing, so the reasoning
   is visible, not just the output. One or two sentences is enough — this
   isn't a report, it's a quick note on why the structure was chosen.
4. **Hand off to the right existing skill for the actual writing mechanics**,
   informed by the framework choice rather than starting from scratch:
   - LinkedIn posts, company social, Reels/short-form video → `social`
   - Cold outreach emails → `cold-email`
   - Website copy, case studies → `copywriting`
   - Blog/Insights post planning → `content-strategy`
   - Google/Meta ad copy → `ads`
   - General nurture or lifecycle email (not cold outreach) → `emails`

   This skill only answers "which structure, and why" — it doesn't replace
   the mechanical guidance (hooks, subject lines, length, platform specs)
   those skills already provide. Don't reimplement what they already do
   well.

5. **If nothing in the six frameworks genuinely fits**, say so rather than
   forcing one on. `docs/content-frameworks.md` is explicit about frameworks
   being *rejected* for certain verticals (e.g. Golden Circle for cold
   email) — that same judgment applies to any new content type not yet
   covered in the doc. When in doubt, extend the doc's reasoning rather than
   guessing.

## When the founder's personal input is required

Two frameworks (Origin Story, and Golden Circle when applied to founder
content) depend on Meet's real personal history — why he started the
agency, what came before, the specific frustration behind the honesty
positioning. Never invent these details. If they aren't already established
in the current conversation, ask for them before drafting anything that
depends on them.
